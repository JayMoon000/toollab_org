매칭 토큰 및 캡처 그룹 상세 내역

자바스크립트(ECMAScript) 정규표현식 핵심 토큰 빠른 참조표

자바스크립트, 파이썬, PHP 등 현대 프로그래밍 언어에서 가장 빈번히 사용되는 메타문자 규칙입니다.

토큰 (Token) 분류 문법 설명 예시 패턴
\d / \D 문자 클래스 모든 아라비아 숫자 [0-9] 일치 / 숫자가 아닌 문자 \d{3} ("123" 일치)
\w / \W 문자 클래스 영문, 숫자, 언더바 [a-zA-Z0-9_] / 단어 문자가 아닌 것 \w+ ("admin_01" 일치)
^ 및 $ 앵커 (위치 지정) 문자열 또는 행의 시작(^)과 끝($) ^start.*end$
(...) / (?:...) 그룹화 캡처 그룹(추출 대상) / 비캡처 그룹(단순 묶기) (abc)+

성능 저하를 막는 정규식 작성 모범 사례

1. 탐욕적(Greedy) vs 게으른(Lazy) 수량자

*와 +는 기본적으로 가능한 많은 문자를 삼키는 탐욕적 방식으로 동작합니다. 뒤에 물음표를 붙인 *?나 +?를 사용하면 일치하는 최소 단위까지만 끊어서 매칭합니다.

2. 파국적 역추적(Catastrophic Backtracking) 방지

(a+)+$처럼 수량자가 중첩된 패턴은 긴 불일치 문자열을 검사할 때 브라우저 탭을 멈추게 만들 수 있습니다. 명확한 문자 클래스를 사용하고 반복 범위를 좁히는 것이 안전합니다.

자주 묻는 질문 (FAQ)

Q. 본 테스터는 어떤 정규식 엔진(Flavor)을 사용하나요?

브라우저 내장 자바스크립트 표준(ECMAScript) 정규식 엔진을 직접 사용합니다. 룩어헤드(Lookahead), 룩비하인드(Lookbehind), 네임드 캡처 그룹(Named Groups) 등 최신 JS 정규식 문법을 완벽히 지원합니다.

Q. 테스트 창에 입력한 비밀번호나 중요 로그 데이터가 서버로 전송되나요?

절대 전송되지 않습니다. 모든 정규식 컴파일과 매칭 연산은 사용자 PC 브라우저의 샌드박스 메모리 안에서만 100% 실행되므로, 민감한 비즈니스 텍스트나 로그 파일도 안전하게 검증할 수 있습니다.
