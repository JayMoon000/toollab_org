CommonMark 마크다운 핵심 문법 빠른 참조표

깃허브(GitHub), 노션(Notion), 옵시디언, 벨로그 등 표준 기술 문서에서 가장 빈번히 사용되는 서식입니다.

요소 (Element) 마크다운 작성 문법 변환되는 HTML 태그
대제목 (H1) # 문서 제목 <h1>문서 제목</h1>

인용구 (Quote) > 인용 내용 작성 <blockquote>인용 내용 작성</blockquote>

웹 퍼블리싱을 위한 마크다운 작성 원칙

1. 시맨틱 제목(Heading) 계층 준수

문서 최상단에 메인 제목(H1)을 1회만 배치하고, 하위 주제는 H2, H3 순서로 순차적으로 내려가야 웹 접근성과 검색엔진(SEO) 크롤러가 문서의 구조를 정확히 파악합니다.

2. 원클릭 HTML 추출 활용

[HTML 복사] 기능을 활용하면 정적 블로그(Hexo, Jekyll), 티스토리 HTML 모드, 뉴스레터 이메일 서식 등에 별도의 변환 프로그램 없이 깨끗한 태그 코드를 즉시 붙여넣을 수 있습니다.

자주 묻는 질문 (FAQ)

Q. 작성 중인 글이 실수로 브라우저를 닫아도 보존되나요?

네. 본 뷰어는 사용자가 글을 타이핑할 때마다 브라우저 로컬 저장소(localStorage)에 자동으로 실시간 캐싱하므로, 탭을 새로고침하거나 브라우저를 다시 켜도 작성 중이던 원고가 복원됩니다.

Q. 외부 서버로 문서 내용이나 개인정보가 전송되나요?

절대 전송되지 않습니다. 모든 마크다운 파싱과 HTML 컴파일 연산은 사용자의 브라우저 메모리 안에서만 100% 자바스크립트로 실행되며 서버 전송 바이트는 0바이트입니다.
